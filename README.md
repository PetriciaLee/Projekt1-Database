## 💻 Setup & Installation

### Prerequisites
Make sure you have a local web server with PHP and MySQL support installed (e.g., XAMPP, WAMP, or Laragon).

### Installation Steps

1. Clone the repository:
   git clone [https://github.com/yourusername/Projekt1-Database.git](https://github.com/yourusername/Projekt1-Database.git)
   cd Projekt1-Database

2. Database Setup:
   - Open PHPMyAdmin or your preferred database client.
   - Create a new database (e.g., projekt1_db).
   - Import the database schema (.sql file if available).

3. Configure Connection:
   - Update your database connection settings in the PHP config file (DB host, username, password, database name).

4. Run the Application:
   - Move the project directory to your local server's root folder (htdocs or www).
   - Open your browser and navigate to http://localhost/Projekt1-Database/index.php.
